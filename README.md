The client for this project was Artemis Financial. They are a consulting firm that helps crate financial plans for their customers. They wished to modernize their software security for their RESTful web application programming interface.

I did an effective job in this project of interpreting the dependency check report and identifying software vulnerabilities. 
It is important to code securely because it prevents attackers from taking advantage of weaknesses that could lead to access of sensitive information and ruin customer trust. Software security helps to protect the organization and their customers. This helps to reduce legal and financial risk that could lead to losses to an organization that they cannot come back from.

The most challenging part of this project was the manual code review. It was difficult to review someone else's code and detect all of the security vulnerabilities that did not align with current best practices.

I increased layers of security by sanitizing inputs, adding private modifiers where appropriate, and validating fields where needed as well. In the future, I would use manual code review and automated scanning tools to detect security vulnerabilties.

I made sure I did not introduce new vulnerabilities after refactoring the code by running a new dependency check and comparing it to the initial one from the original code. 

I used Secure Coding Guidelines for Java SE as a resource for this assignment. It contains information on secure coding practices for several different security categories.

From this assignment, I would show future employers my ability to manually review code, report the vulnerabilities, and execute a plan to mitigate those vulnerabilities as well.
